# Tileborn
**Build the world, tile by tile**

Tileborn is a **small personal project**: a tile-based strategy and building game written **entirely in Python**, without using a game engine.

The game focuses on **progression through eras** and long-term development. The player gathers resources, constructs buildings, and gradually expands control over a grid-based world that starts in a **medieval setting** and evolves into a **modern and industrial civilization** through a tech tree (not implemented yet).


## Project Status

**Tileborn is NOT in a playable state yet.**

The project is still in **early development**, and there is no finished gameplay loop or polished experience at the moment.  
The current goal is to reach a **first playable prototype (v0.1)** that demonstrates the core systems and progression mechanics (which i'll get to in one or two weeks from now: 06/01/2026).

## Running the Project

If you want to explore or test the project:

- You can run it directly using:
    main.py
Or run:
    python build.py

which will generate an executable build.

Keep in mind that this is a work in progress, so bugs, missing features and incomplete systems are expected.
