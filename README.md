# Tileborn
Build the world, tile by tile

Tileborn is a tile-based strategy and building game focused on advanced era systems and satisfying progression. The player gathers resources, constructs buildings, and gradually expands control over a grid-based world that surpass eras, starting in an medieval world, and evolves to an modern and industrial civilization.

The project is currently in early development, with the goal of reaching a first playable version (v0.1) that demonstrates the core gameplay loop.
